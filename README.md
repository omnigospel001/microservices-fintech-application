An exceptional Multi User Microservices Fintech Application designed from the root.

When a user registers, a 10 digit account number is generated for him automatically, there by enabling him for peer to peer transactions.

A User can Deposit fund to his account, Withdraw fund from his account and Transfer funds to another registered user easily.

This Fintech Application is packed with different layers of notifications from the Deposit Alerts to the Withdrawal Alerts and to the Transfer Alerts to the receiver and the sender.

This is the base foundation of how Fintech and Banking applications work in the real world. 

I built this with the real world multi user Fintech Application in mind.
